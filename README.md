# Search UI Fragment (`search-ui`)

> **Micro-Frontend Search Experience for Composable Digital Commerce**

Provides standalone and embeddable search components including `<SearchBar>`, instant-typeahead `<SearchModal>`, and full `<SearchFragment>` results with spatial cabinet clearance filters.

---

## 🏗️ Exported Components

- `<SearchBar />`: Minimal search input for navbar embedding with `⌘K` badge.
- `<SearchModal />`: Floating instant-search overlay with typeahead suggestions and clearance slider.
- `<SearchFragment />`: Full search results page with faceted sidebar and sorting.

---

## 🚀 Running Standalone Harness

```bash
npm install
npm run dev     # Runs harness on port 5179
npm run build   # Compiles standalone bundle
```
